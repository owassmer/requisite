# 002-2 The approved estimand is a share among items in a business's voice: a two-phase ratio estimator

## Why
F4's objective, approved by Owen at G1, defines its estimand as a ratio: among the frame's items written in a small
business's own voice (the denominator), the share that describe that business as exposed to a pending event of the
class (the numerator), overall and for each event family. requisite/discovery/inference.py estimates frame means of
one indicator under the two-phase design (decisions, "two-phase" and "Wide inference as built"). A ratio of two such
means is not a mean. Reporting the numerator's frame share as the estimand would answer a different question. Dividing
two intervals' ends would give an interval with no stated coverage. Both are escape routes (design/posture.md).
Owen's gold labels arrive Monday from 10:00 ET; the estimate shown in the demo (spec §15 beat 1) is this one.

## What to build
In inference.py, `two_phase_ratio`: the estimate of R = theta_num / theta_den, where theta_num and theta_den are the
frame means of two indicators observed on the same gold items, with model predictions f_num and f_den. It has the same
design inputs as two_phase_difference, and the same phase-2 strata (the one definition, _phase2_strata).
- The point estimate is the ratio of the two plain difference estimates (lam = 1).
- The interval is Fieller's: the set of R for which theta_num_hat - R theta_den_hat lies within z standard errors of
  zero (z for the existing interval's level). The standard error is that of the plain (lam = 1) difference estimator of
  the combination y_num - R y_den with prediction f_num - R f_den, estimated by the design's own unbiased two-phase
  variance estimator (the one inference.py already proves exact), which is a quadratic in R. The point estimate and
  the interval come from that one estimator, so the estimate always lies in its own set. The existing mean interval
  is a score interval because a plain interval under-covers with few gold items per stratum; the combination is not a
  0/1 label, so that construction does not carry over as it is. Measure Fieller's coverage first; where it falls short
  of nominal in the settings F4 has (about 130 gold items over up to four phase-1 strata, two phase-2 strata each),
  find the cause and fix it in the interval, by the same idea (the variance evaluated where the value is tested) or
  another you show covers, and report both.
- Where the set is not a bounded interval (theta_den not distinguishable from zero), report it as what it is, the union
  of rays or the whole line, with its reason, never truncated to a range. The numerator's items are a subset of the
  denominator's by the estimand's definition, so R lies in [0, 1]: return the raw set and its intersection with [0, 1],
  which loses no coverage.
- Families: the numerator for a family is the indicator in the family's numerator; the denominator is shared.
  Return each family's ratio from the same call; each family's interval is marginal, and is labelled so.
The estimand's own definitions (which answers of which questions make an item count in the numerator or the
denominator) stay with the caller. The wide flow's estimate step, which calls this function, is the coordinator's: it
needs the event families the run defines, which are not built yet, so this task ends at the function and its tests.
The biased-judge test below is a test of this function, not a new registry item.
