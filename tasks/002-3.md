# 002-3 The mean's score interval, from the exact category mixture the ratio uses

## Why
A wide run's estimate is shown with an interval whose coverage is measured, not assumed (addendum A07 §8.5; spec §7.4).
Task 002-2 found that the mean's score interval (requisite/discovery/inference.py, `_score_model`) over-covers when the
judge separates well. It floors 1 - 2·lam·delta at 0, so where the gap delta in mean prediction between labelled-1 and
labelled-0 items exceeds 0.5, the label part of a cell's residual variance is kappa·p(1-p)·delta² instead of the exact
kappa·p(1-p)·(1-delta)². That is about five times the variance at delta = 0.7. Measured by `measure_coverage`: 1.000 on a
rare-class frame (width 0.121), and 0.975 in F4's shape. An interval that is wider than the design warrants overstates
what is unknown. That is a false statement about the world as much as an under-covering one is.

The ratio's score set (`two_phase_ratio`, landed in 002-2) evaluates the variance as the exact mixture over the
categories an item's labels put it in, with the gold's mean predictions in each. 002-2 reports that when every item is
in the denominator, the ratio's path is exactly the mean interval's path; check that before you build on it, since the
floor should make them differ where delta > 0.5. Either way there should be one definition: a mean indicator is the
ratio with a denominator that holds every item, or both read the one mixture variance.

## What to build
The mean's score interval reads the same exact category-mixture variance as the ratio's score set, by one definition in
inference.py. No floor: the exact mixture is non-negative by construction. Keep what the mean's interval already gets
right: the score construction (the variance evaluated where the value is tested), the take-whole rule, a cell's
unshown category getting no credit for separation, the cross-fitted lam where it applies, and the bounds within [0, 1].
`_score_model` and whatever duplicates the ratio's mixture go. Where lam is not 1, say how the mixture carries it, and
show that it is exact.
